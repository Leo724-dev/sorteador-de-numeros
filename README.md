# 🎲 DevSorteio - Sorteador de Números Dinâmico

Este projeto é uma aplicação web interativa desenvolvida para realizar o sorteio aleatório de números dentro de um intervalo customizado definido pelo usuário, contando com um design moderno, festivo e de alto impacto visual.

## 📝 Sobre o Projeto

O foco principal é oferecer uma ferramenta simples, rápida e visualmente atraente para a realização de sorteios e premiações:
- **Intervalo Customizável:** O usuário define livremente o valor mínimo ("Entre") e o valor máximo ("E") para delimitar o escopo do sorteio.
- **Geração Aleatória Confiável:** Utiliza a lógica matemática do JavaScript para garantir a imparcialidade e a aleatoriedade exata dos resultados gerados.
- **Estética Imersiva:** Apresenta uma interface temática estilizada em tons de vermelho com efeitos de iluminação de palco e confetes, ideal para engajar o público durante dinâmicas de sorteio.

## 📸 Demonstração

Você pode visualizar o projeto online através do link: 👉 https://leo724-dev.github.io/sorteador-de-numeros/

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica do formulário de entrada de dados, botões de ação e elementos de exibição do resultado.
- **CSS3:** Estilização avançada para composição do cenário visual (efeito spotlight e confetes de fundo), customização de campos de texto integrados e design responsivo.
- **JavaScript (ES6+):** Lógica matemática usando os métodos `Math.random()` e `Math.floor()` para geração do número aleatório, além da manipulação dinâmica do DOM para leitura dos inputs e exibição imediata do resultado.

## ✨ Funcionalidades

- [x] **Sorteio com Intervalo Personalizado:** Liberdade total para escolher os limites mínimo e máximo do sorteio.
- [x] **Geração Instantânea:** Processamento imediato e exibição do número sorteado ao clicar no botão.
- [x] **Identidade Visual Temática:** Layout imersivo projetado para simular o clima de uma premiação ou palco de eventos.
- [x] **Responsividade:** Interface adaptada e otimizada para funcionar perfeitamente tanto em dispositivos móveis quanto em desktops.
